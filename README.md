# PimsAtlas

This repository contains the R code and data assets for the PIMS Atlas Software.

## How to Run This Project
1. Click the green **Code** button at the top right of this page and select **Download ZIP**.
2. Extract the downloaded ZIP folder anywhere onto your local computer.
3. Open the folder and launch the `PIMS Atlas.R` file using **RStudio**.
4. Ensure all accompanying data files remain in this exact same folder directory so the script can locate them automatically.
